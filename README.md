# Arduino DC Motor Control Using L293D

This project demonstrates controlling four DC motors using an Arduino Uno and an L293D motor driver.
The system is programmed to perform different movement sequences:
- Move forward for 30 seconds.
- Move backward for 60 seconds.
- Turn right and left alternately for 60 seconds.

## Components Used

- Arduino Uno
- L293D Motor Driver
- 4 DC Motors
- 9V Battery
- Breadboard
- Jumper Wires

## Software Used

- Tinkercad Circuits
- Arduino IDE

## Circuit Design

The four DC motors are grouped into two sides:
- Two motors for the right side.
- Two motors for the left side.

Each side is controlled through the L293D motor driver to achieve forward, backward, and turning movements.
